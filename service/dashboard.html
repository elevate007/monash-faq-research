Interpret monitoring carefully

These counters describe service behavior. Guardrail blocks and lexical coverage are proxies, not a measured hallucination rate. Grounded mode returns exact snapshot text selected from retrieved records; it can still select an irrelevant record or stale fact. Generative mode can pass surface checks while remaining factually wrong.

Request and answer bodies are not recorded in operational logs or metrics. API keys stay in this page's memory and are never saved to browser storage.
